# PS4 System Check

واجهة عربية تجريبية بخمسة أزرار لإصدارات النظام وشعارك في المنتصف.

## التشغيل
- افتح `index.html` في المتصفح.
- ارفع محتويات هذا المجلد إلى مستودع GitHub.
- من **Settings → Pages** اختر النشر من الفرع `main` ومجلد `/ (root)`.

**ملاحظة:** صفحة ويب عادية لا تستطيع قراءة إصدار نظام PS4 الحقيقي بشكل موثوق. يعرض المشروع معلومات المتصفح المتاحة فقط، وتختار الإصدار يدويًا.
