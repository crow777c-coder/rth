# Crow 777 — PS4 System Check + Golden Hen launcher

واجهة عربية تحمل شعار Crow 777، مع تضمين ملفات مشروع Golden Hen الأصلي داخل `goldhen/`.

## السلوك
- أزرار 13.02 و13.04 و13.50 و13.52 تفتح مشغّل Golden Hen المضمّن.
- المشغّل يعتمد على اكتشاف إصدار النظام الفعلي وجداول الملفات الموجودة في مشروع Golden Hen؛ اختيار الزر لا يفرض إصدارًا على الجهاز.
- زر 14.00 موجود في الواجهة الأصلية، لكنه لا يُعامل كإصدار مدعوم تلقائيًا.

## النشر
ارفع محتويات المجلد إلى جذر المستودع، ثم فعّل GitHub Pages من الفرع المطلوب ومجلد `/ (root)`.
